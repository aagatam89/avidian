Подключитесь к VPN и установите корпоративный клиент по официальной инструкции.

2

Войдите в Mattermost MCP

Выполните avito-ai mcp auth mattermost. Имя пользователя определится из этой сессии.

3

Скачайте и запустите Avidian

Выберите инструкцию для своего компьютера и выполняйте пункты по порядку.

Windows — подробно

  1. Нажмите выше «Скачать для Windows».
  2. Откройте папку «Загрузки» и найдите Avidian-Windows.zip.
  3. Нажмите на архив правой кнопкой мыши → «Извлечь все…» → «Извлечь». Не запускайте установщик прямо из ZIP.
  4. Откройте появившуюся папку Avidian-Windows.
  5. Дважды нажмите Install-Avidian.bat. Если Windows попросит подтверждение, убедитесь, что файл скачан с этой страницы, и разрешите запуск.
  6. Дождитесь сообщения об успешной установке. Затем откройте ярлык Avidian на рабочем столе или в меню «Пуск».

Если окно сразу закрылось: откройте START-HERE.txt в распакованной папке и повторите шаги. Архив должен быть полностью распакован.

macOS — подробно

  1. Нажмите выше «Скачать для macOS».
  2. Откройте Finder → «Загрузки» и дважды нажмите Avidian-macOS.zip, чтобы распаковать архив.
  3. Откройте Terminal: нажмите ⌘ Command + Пробел, напишите Terminal и нажмите Enter.
  4. В окне Terminal напечатайте zsh и один пробел: zsh
  5. Вернитесь в Finder, откройте папку Avidian-macOS и перетащите файл Build-Avidian.command прямо в окно Terminal. Рядом с zsh появится полный путь к файлу.
  6. Нажмите Enter и не закрывайте Terminal. Первая сборка может занять несколько минут.
  7. Когда появится строка Built … Avidian.app, откройте в Finder папку Avidian-macOS → release и дважды нажмите Avidian.app.

Если написано «can't open input file»: был введён только файл без пути. Повторите шаги 4–6 и обязательно перетащите Build-Avidian.command из Finder. Если не найден Node.js 22 или uv, Avidian откроет официальную страницу установки: установите компонент, полностью закройте Terminal и повторите запуск. Если значок Avidian подпрыгивает и исчезает, новая версия покажет окно с причиной — нажмите «Открыть журналы».

Важно для macOS

Safari иногда сам распаковывает ZIP и показывает синюю папку Avidian-macOS — это нормально, если внутри есть Build-Avidian.command, папки app и backend. Если папка пустая или весит почти 0 байт, удалите её и скачайте файл заново: полноценный архив занимает примерно 3,4 МБ.
